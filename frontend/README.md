# BMIS Frontend

React + TypeScript + Vite + Tailwind CSS single-page application for the
Barangay 2 Management Information System.

Phase 1 contains the login page, the authenticated application shell, and the
role-aware dashboard. Operational modules are intentionally not implemented yet.

```bash
npm install
npm run dev       # proxies /api to http://localhost:4000
npm run build
npm run test
npm run lint
npm run typecheck
```

See the repository root [`README.md`](../README.md) and
[`docs/`](../docs) for setup, architecture, security, and phase scope.
